# USAR Bull Case｜美国稀土

## 1. 美国真正的竞争者很少

稀土不是"有没有矿"这么简单，而是能不能完成开采 → 分离 → 金属 → 磁铁整条产业链。

USAR正在建立的，正是一条西方独立的 Mine-to-Magnet 供应链。

## 2. 核心逻辑：去中国化

稀土已经不是普通商品，而是国家安全资产。

芯片、导弹、雷达、无人机、电机都离不开高性能稀土磁铁。

中美关系越紧张，美国就越不能把关键供应链交给中国。

## 3. 管理层更替很有意思

Barbara Humpton 有 Siemens Government Technologies、Lockheed Martin、Booz Allen 背景。

她这一阶段完成的是：**政府关系 → 融资 → 战略布局。**

现在她退休，由拥有40年矿业与稀土经验的 Thras Moraitis 接任。

下一阶段变成：**矿山 → 生产 → 整合 → 规模化。**

先找懂政府的人把路铺好。再找懂矿的人把矿挖出来。

## 这就是我看 USAR 最大的 Bull Case

它赌的不是单纯的稀土价格。

它赌的是美国必须建立一条不依赖中国的稀土供应链。
