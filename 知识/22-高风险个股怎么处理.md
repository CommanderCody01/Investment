# ⚠️ 高风险个股怎么处理

高风险组不是"不能买"，而是**不能用低风险股票的仓位和方法去处理。**

这组更需要控制：**仓位、入场价格、事件风险、新闻和政策变化。**

总体原则：

> **小仓位、慢一点、晚一点确认。**
> 不要因为故事很好就急着重仓。

---

## ① 好公司，但估值和波动很高

**AVAV / PLTR / KTOS / TSLA**

这些公司有真实业务、真实收入，也有很强的长期 Narrative。

问题不是公司差，而是市场预期通常很高，股价容易因为**估值、财报或者 Narrative 降温**出现很大的回撤。

**做法：**
- 不要追高
- 等明显回调以后再考虑
- IV 高的时候可以研究 Sell Put，但前提是你真的愿意接正股
- Call 也可以用，但仓位要小

**简单理解：好公司，但是一定要等价格。**

---

## ② 真实业务，但受周期 / 政策 / 经营环境影响

**GEO / JBLU / SFD / VITL / ALB**

这些不是纯投机公司，但利润和股价容易受到外部环境影响。

- **GEO** — 政策和政府合同
- **JBLU** — 油价、航空周期、经营修复
- **SFD** — 食品和肉类价格
- **VITL** — 鸡蛋供应周期
- **ALB** — 锂价和资源周期

**做法：**
等坏周期或者坏消息把价格打下来以后，再小仓位进入。

Sell Put 可以很好用，但要记住：

> **高 IV 往往是因为市场真的认为风险很高。**

不要只是看到 Premium 高就卖。

---

## ③ Turnaround｜业务扭转

**RXST**

RXST 有真实产品和收入，但现在真正需要观察的是：

> **新管理层能不能把销售和增长重新做起来。**

这种股票的特点是：

> **便宜可以继续便宜。**
> 但如果 Turnaround 被确认，股价也可能很快重新定价。

**做法：**
- 小仓位
- 先看管理层执行
- Sell Put 不要卖得太近
- 如果基本面开始确认改善，小额 Call 也可以用来表达上涨

---

## ④ 真正高度投机

**UMAC / USAR / DJT / CCXI / AGLT / BIOA**

这些股票可能拥有非常大的 Narrative：

- **UMAC** — 美国无人机供应链
- **USAR** — 美国稀土独立
- **DJT** — 政治 + AI能源 / 核聚变
- **CCXI / AGLT** — 人形机器人
- **BIOA** — 长寿生物科技

但这些公司还需要证明：**融资、技术、规模化、临床结果、并购完成、商业化。**

所以这组不能用："跌了30%，所以更便宜了。" 这种思维。

一个关键事件失败，就可能直接改变整个 Thesis。

**这组最重要的原则：**

> **Small. Lazy. Late.**

- **Small** = 仓位小
- **Lazy** = 不要天天折腾
- **Late** = 宁愿确认以后晚一点买，也不要为了早进去承担全部风险

这一组 Sell Put 反而要更加谨慎。因为高 IV 可能意味着真正的 **Binary Risk**。

有时候小额 Call 反而更干净：**最大亏损提前知道，也不会被迫接下一大堆股票。**

---

## 📌 高风险组总结

| 分类 | 股票 |
|---|---|
| 好公司但贵 / 波动大 | AVAV / PLTR / KTOS / TSLA |
| 周期 / 政策 / 经营风险 | GEO / JBLU / SFD / VITL / ALB |
| Turnaround | RXST |
| 高度投机 | UMAC / USAR / DJT / CCXI / AGLT / BIOA |

---

## 最后记住

**低风险组：找便宜，慢慢拥有。**

**高风险组：等机会，用小仓位买一个不对称的可能性。**
